# Character Counter

The empty state of a character counter design, built with HTML and CSS only as the lab project for the UI Essentials course in the Frontend specialization.

## Features

- Text area with hover and focus states
- Custom-styled "Exclude Spaces" and "Set Character Limit" checkboxes
- Character, word and sentence stat cards with decorative patterns
- Letter density section in its empty state
- Light and dark themes that follow the system setting (the theme toggle is decorative)
- Responsive layout for mobile, tablet and desktop

## Built with

- Semantic HTML
- Modern CSS: custom properties, nesting, grid, `prefers-color-scheme` and `clamp()`

## Getting started

Open `index.html` in a browser. Nothing needs to be installed.

## Project structure

```
├── index.html     Page structure
├── styles.css     Design tokens, themes, layout and components
└── assets/        Logos, icons, card patterns, background textures and favicon
```

## Accessibility

- Visible focus indicator on every control
- Labelled form controls
- Text meets WCAG AA contrast in both themes

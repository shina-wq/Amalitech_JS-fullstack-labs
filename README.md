# Amalitech JS Fullstack Labs

Lab projects completed during the Amalitech JavaScript Fullstack Apprenticeship Programme.

Each lab lives in its own folder, grouped by course. Every lab has its own README with details on what it does and how to run it.

## Labs

| Lab | Course | Description |
| --- | --- | --- |
| [Character Counter](Foundations/FEM01-UI-Essentials_character-counter) | UI Essentials | Responsive HTML and CSS layout of a text analyzer, in light and dark themes |
| [Character Counter](Foundations/FEM02-JS-Essentials_character-counter) | JavaScript Essentials | Real-time character, word and sentence counts, limit warnings, reading time and letter density |
| [Task Manager API Client](Foundations/FEM03-JS-Advanced_task-manager-api) | JavaScript Advanced | Interactive CLI that fetches, filters, sorts and analyzes tasks from JSONPlaceholder, with retries, caching and rate limiting |
| [Note-Taking App](Foundations/FEM04-DOM-Browser-APIs_note-taking-app) | DOM & Browser APIs | Notes with tags, archiving, live search, themes, session drafts and geolocation, saved in localStorage |
